# 司空 · 从此处生枝

> 写下你已知的一点，从它身旁去往未见之处。

「司空」是一个以卡片为核心的 AI 文字生成与发散应用。输入一个短句，它会生成多种「意外」变体卡片，并提供解说、收藏、浏览和诗文会 / 书会玩法，内容由 DeepSeek 生成。

## 功能

- 七种卡片：沙海、湮律、不守、盲诗、全书、尔反、空
- 生成过程流式展示与卡片解说
- 收藏抽屉：保存、浏览与删除
- 浏览模式、诗文会 / 书会等扩展玩法

## 新手教程（新手指南）

「司空」不给你"最匹配的答案"，而是把你从一个词带到意想不到的地方。下面从首页讲到浏览界面，讲清每一个可点的东西。

> ⚠️ **必读：使用司空必须配置有效的 DeepSeek API Key，否则无法运行。且路径不能包含中文，否则start.bat无法正常启动** 未配置 Key 时应用无法生成任何内容（见下方第一步 / 第五节设置）。

### 一、首页怎么看、怎么用

打开应用，首页是一个大输入框，和一句「写下近来萦绕于你的一事一物」。

#### 1.1 左上角 Logo

首页左上角的「司空 SIKONG」Logo 其实是一个**可点击按钮**。点它，会打开**「留印」抽屉**（见第五节）。

#### 1.2 大输入框（起点）

中间这个大输入框，就是你的**起点**。写一个词、一句话、或一段近来的念头都行。适合当起点的，是那种带一点画面或情绪的词，比如：

- 「雨夜」
- 「旧车票」
- 「海边的旧书店」
- 「今天下午的云」

**字长限制**：最多 **28 个汉字**。输入框右下角会实时显示 `字数 / 28`，超过会变红提示「太多了，先控制在28字以内」。

#### 1.3 引擎选择器（输入框上方）

输入框上方有一个下拉控件，默认显示**「沙海 ⌄」**。点开会列出全部七种引擎，每个都带一句说明：

| 引擎 | 说明 |
|---|---|
| 沙海 | 随机偏离 |
| 湮律 | 谐音错听 |
| 不守 | 字形拆解 |
| 尔反 | 逐词取反 |
| 盲诗 | 诗句相遇 |
| 全书 | 随机建议 |
| 空 | 失忆续写 |

**选哪个，决定了你点「由此生枝」后会用哪种方式生成卡片。** 想先随便玩玩，选「沙海」；想要更靠近你的词、更克制，选「尔反」或「空」。

#### 1.4 「由此生枝」按钮

输入框右下角的大按钮。**在输入框写好起点、选好引擎后点它**，就会进入卡片浏览界面。空输入或超 28 字会提示错误，不会进入。

#### 1.5 输入时的候选建议

当你输入一个字以上时，输入框下方会**浮出最多 7 个候选话题**。这些是司空给你"顺手的下一根枝"。点任意一个，会**自动填进输入框**。候选里有些字会被**标红**，那是提示你"这个词和你输入的字有字形/字音的关联"。

#### 1.6 「猜你不喜欢 / 猜别人喜欢」

输入框下方有一排小字推荐，默认是**「猜你不喜欢」**。点它，会切换到**「猜别人喜欢」**（两个模式来回切换）。每个模式下面有 3 个话题，点一下就会填入输入框。这是让你快速找到一个"不太想走、或别人会喜欢"的方向的入口。

#### 1.7 点击「由此生枝」后的过场动画

点「由此生枝」后，会有**约 1 秒的汉字飞散动画**（一堆汉字聚拢到中间），然后进入卡片浏览界面。这个动画只是氛围，不用等它，屏幕会自然过渡。

---

### 二、进入浏览界面：顶部栏

进入后，你会看到一张卡片和顶部的一排控件。这是司空最核心的界面。

#### 2.1 左上角「司空 SIKONG」

和首页一样，点它打开**「留印」抽屉**。

#### 2.2 三个阅读模式（新枝 / 驻足 / 探索）

顶部中间有三个 Tab，决定你**这次怎么继续走**：

| 模式 | 作用 | 什么时候用 |
|---|---|---|
| **新枝** | 底部出现**搜索输入框**，可**换一个起点**重新生枝 | 想彻底换个主题 |
| **驻足** | 底部出现**引擎选择栏**，可**换引擎**再生成一张同起点的卡 | 想换角度看同一个词 |
| **探索** | 顶部无额外输入，点「继续探索」就往下走 | 默认，边走边看 |

#### 2.3 卡片右上角

显示**「本卡片由 ⌜XX⌟ 引擎生成」**——告诉你当前这张卡是哪个引擎做的。

---

### 三、看懂一张卡片

卡片是司空的主体，所有生成结果都以卡片呈现。

#### 3.1 卡头（header）

左上角是你**输入的原词**（起点），右上角是**生成引擎名**。

#### 3.2 卡片正文区

根据引擎不同，正文区展示不同内容：

- **沙海 / 湮律 / 不守 / 尔反**：展示 **① 意外方向标题 → ② 一段联想解说 → ③「何以相遇」的文字说明**（你的原词和意外方向怎么扯上关系的）
- **盲诗**：展示**两句诗**，中间用 `/` 隔开（随机凑到一起的两句）
- **全书**：展示**一句"答案之书"式的话**
- **空**：展示**一段延续你起点的文字**，会一句一句**流式浮现**，底部有「继续续写」，可再续写直到达到上限（此时显示「续写已达到上限」）

#### 3.3 卡片底部按钮区

| 按钮 | 作用 |
|---|---|
| **何以相遇** | （沙海/湮律/不守/尔反：直接点开；盲诗/全书：点「何以相遇」会先"揭示"再打开）**展开解释**：你的原词和这张意外方向到底怎么联系上的。再点一次「收起解释」可关闭 |
| **避开** | 这个方向我不要，**跳到下一张不同方向**的卡 |
| **留印** | **收藏**这张卡。收藏后按钮变「已留印」，卡片上会盖一个「留」字章 |
| **继续探索** | （右下，探索模式）**往这个方向再走远一点**，换一批生成 |
| **再遇一则** | （驻足模式）换引擎再生成一张同起点的卡 |

> 空卡片默认**没有**「何以相遇」和「继续探索」按钮（它只能续写），只有「避开」和「留印」。

#### 3.4 滑动手势（探索模式）

在探索模式下，你可以在卡片上**左右滑动**来换方向，类似翻卡。上下滑动也有不同效果：
- **水平滑动**：往左/右换方向
- **垂直滑动**：往上/下换方向
- **斜向滑动**：对角换方向

松手后卡片会飞出去，然后加载下一张。这和在按钮上点「继续探索」效果类似，但更顺手。

#### 3.5 卡片动画状态

卡片有明显动画：进入时会从边框放大浮现；退出时按你滑动的方向飞出；「避开」会有一条横线划掉；「留印」会盖一个朱红「留」字章。

### 四、七种引擎详解

选择引擎，就是选择"用哪种方式让你的词偏出去"。下面按实际生成逻辑讲清楚：

#### 4.1 沙海（随机偏离）
**完全不管你的输入**，直接让模型**随机开一个新话题**，再把你的原词和这个新话题"扯上关系"。是最发散、最"意外"的引擎。

- 感受：从你的词旁边**凭空长出一根完全陌生的枝**
- 适合：想被狠狠带偏、想看想象力上限

#### 4.2 湮律（谐音错听）
从你的词里**挑一个词，把它"听错/打错"成另一个音近词**，再用这个错听的词开话题。

- 感受：听岔了的话，反而更好玩
- 适合：喜欢谐音梗、文字游戏

#### 4.3 不守（字形拆解）
从你的词里**挑一个词，拆它的部首/构件**，再把每个构件联想成抽象意象，用这些意象开话题。

- 感受：把字拆开，重新拼成别的东西
- 适合：喜欢汉字构造、字形联想

#### 4.4 尔反（逐词取反）
把你输入的每个词**逐词取反**，得到一组反义词，再用反义词的方向开话题。

- 感受：恰恰相反，是最自然的意外
- 适合：想要"最克制、最贴着你词"的偏移

#### 4.5 盲诗（诗句相遇）
模型**随机写两句现代诗**（上句由你的词引申，下句完全随机），凑成一首"双盲诗"，并解释两句为何相遇。两句都**没有标点**。

- 感受：诗根本不需要懂，碰在一起就好
- 适合：想要诗意的、不可名状的氛围

#### 4.6 全书（随机建议）
模型扮演**答案之书**，**完全随机**给你抽一句"建议/词"，再解释它和你的原词可能有什么关系。

- 感受：你说的话，被书"怼"了一句
- 适合：想要一句带着玄学感的话

#### 4.7 空（失忆续写）
从你的词开始，**延续写一串句子**，让熟悉的词慢慢走向陌生的地方。会**流式逐句浮现**，点「继续续写」可以接着写，**写到上限（30 句）后显示「续写已达到上限」**。

- 感受：让熟悉的词慢慢走远
- 适合：想要一段流动的、有画面感的文字

### 五、留印抽屉与设置

#### 5.1 打开留印抽屉

首页左上角（点 Logo）、浏览界面左上角（点「司空 SIKONG」）都能打开。里面展示你**收藏过的所有卡片**（留印），每条显示 `原词 → 意外方向` 和一句摘要。

#### 5.2 抽屉里可做的事

- **点一条留印**：直接跳到那张卡（如果起点还在）
- **删一条**：单条删除
- **清空所有**：一键删除全部留印

#### 5.3 设置（在抽屉底部）

抽屉底部有**「设置」**按钮。点开后有：

| 区 | 内容 |
|---|---|
| **LLM 配置** | Provider / 模型名称 / API Base URL / API Key，填完点「保存并刷新」。页面下方会显示「当前：xx · 模型 · 已连接/未连接」 |
| **留印管理** | 一键「删除所有留印」 |
| **教程** | 一个"重置教程"按钮（重置新手引导提示） |

**这就是配置 DeepSeek Key 的地方**：填好 Provider、模型名、地址、Key，点「保存并刷新」，看到「已连接」就成功了。Key 只存在本地，不会上传。

---

### 六、快速上手 3 步

1. **配 Key**：首页 → 留印 → 设置 → 填 DeepSeek Key → 保存并刷新 → 显示「已连接」
2. **开一张卡**：首页输入起点（如「雨夜」）→ 选引擎 → 「由此生枝」
3. **玩起来**：卡片上点「继续探索」往下走、点「何以相遇」看它怎么解释、点「留印」收藏、点「避开」换方向

## 技术栈

- 前端：Vite 5 + React 18
- 后端：Node.js（原生 HTTP 服务，无框架）
- 模型：DeepSeek（OpenAI 兼容的 chat/completions 接口）
- 包管理：pnpm（也兼容 npm）

## 目录结构

```
src/        前端 React 源码
server/     后端 API、模型适配与本地数据文件
scripts/    开发与一键启动脚本
public/     静态资源
```

## 快速开始

### 方式一：一键启动（推荐）

- Windows：双击 `start.bat`
- macOS / Linux：运行 `./start.sh`

脚本会自动完成：检查 Node 环境 → 安装依赖 → 检测是否已配置 DeepSeek API Key → 未配置时提示一键填写或跳过 → 启动前后端服务。

启动完成后打开 <http://localhost:5173>。

### 方式二：手动启动

```bash
pnpm install
pnpm dev
```

打开 <http://localhost:5173>。首次使用可在页面「设置」中填写 DeepSeek API Key 并保存。

## 环境要求

- Node.js >= 18
- pnpm 或 npm

## API Key 配置

内容生成依赖 DeepSeek，需要自行到 [DeepSeek 开放平台](https://platform.deepseek.com/) 申请 API Key。

以下三种方式任选其一：

1. 运行一键启动脚本，按提示填写。
2. 打开应用后在「设置」中填写并保存。
3. 手动创建 `server/model-config.json`，格式如下：

```json
{
  "provider": "deepseek",
  "baseUrl": "https://api.deepseek.com/v1",
  "model": "deepseek-chat",
  "apiKey": "sk-你的密钥"
}
```

密钥与本地数据文件已被 git 忽略，不会提交到仓库：`server/model-config.json`、`server/.env`、`server/.env.local`、`server/saved-cards.json`。

## 运行与部署

- 开发模式：`pnpm dev`（前端 5173，后端 8787，`/api` 自动代理到后端）
- 生产预览：`pnpm preview`（构建前端到 `dist`，由后端在 8787 提供静态文件）
- 检查与测试：`pnpm check`（服务端测试 + 前端构建）；`pnpm test:server`

部署注意：后端会把用户收藏写入 `server/saved-cards.json`、把页面配置写入 `server/model-config.json`，因此建议部署到有持久磁盘的 Node 环境（VPS / 容器）。如果使用无状态的 Serverless 平台，需要先改造本地存储层。
